### 💰 Personal Finance Planner

A responsive personal finance planning application built with **React and Material UI**.

Users can manage income and expenses, organise transactions, track payment status and visualise financial activity through monthly and yearly reports.

The application uses **LocalStorage for client-side data persistence**, supports English and Brazilian Portuguese, and includes automated tests.

**React · JavaScript · Material UI · React Router · Chart.js · LocalStorage · Jest · React Testing Library**
